# Sole Studio

A textured Shopify sneaker with three original material variants.

## Run

From the repository root, run `npm run dev` and open http://127.0.0.1:4320/projects/sneaker-studio/.

## Interaction

Switch colorways, adjust surface roughness, or enable the turntable.

## Files

`index.html` is the standalone entry point. `scene.js` owns this project’s model, controls, and animation. Shared rendering and interface code lives in `../../shared/`.

Model and font attribution is recorded in the root `CREDITS.md`.
