# Key / Form

An original procedural keyboard with case, circuit board, individual caps, legends, and switch stems.

## Run

From the repository root, run `npm run dev` and open http://127.0.0.1:4320/projects/keyboard-builder/.

## Interaction

Change palettes, separate its layers, switch underglow, click keys, and type with the scene focused. Sounds are synthesized after interaction.

## Files

`index.html` is the standalone entry point. `scene.js` owns this project’s model, controls, and animation. Shared rendering and interface code lives in `../../shared/`.

Model and font attribution is recorded in the root `CREDITS.md`.
