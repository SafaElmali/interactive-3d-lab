# Small Hours

An original procedural neighborhood with four buildings, streets, trees, lamps, windows, and moving cars.

## Run

From the repository root, run `npm run dev` and open http://127.0.0.1:4320/projects/miniature-city/.

## Interaction

Change the time of day, stop traffic, or select a building using the scene or control panel.

## Files

`index.html` is the standalone entry point. `scene.js` owns this project’s model, controls, and animation. Shared rendering and interface code lives in `../../shared/`.

Model and font attribution is recorded in the root `CREDITS.md`.
