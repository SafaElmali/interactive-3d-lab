# Essence

An original procedural glass perfume bottle, liquid volume, cap, atomizer, and particle mist.

## Run

From the repository root, run `npm run dev` and open http://127.0.0.1:4320/projects/perfume-collection/.

## Interaction

Change fragrance colors, lift the cap, spray, and frost the glass.

## Files

`index.html` is the standalone entry point. `scene.js` owns this project’s model, controls, and animation. Shared rendering and interface code lives in `../../shared/`.

Model and font attribution is recorded in the root `CREDITS.md`.
