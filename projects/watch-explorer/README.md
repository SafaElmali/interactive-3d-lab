# Second Nature

An original procedural watch with strap, case, movement details, dial, hands, and crystal.

## Run

From the repository root, run `npm run dev` and open http://127.0.0.1:4320/projects/watch-explorer/.

## Interaction

Change strap and dial colors, separate the case layers, and switch between local time and accelerated animation.

## Files

`index.html` is the standalone entry point. `scene.js` owns this project’s model, controls, and animation. Shared rendering and interface code lives in `../../shared/`.

Model and font attribution is recorded in the root `CREDITS.md`.
