# Daily Ritual

Original procedural beans, a hand grinder, ceramic cup, coffee surface, milk design, and steam.

## Run

From the repository root, run `npm run dev` and open http://127.0.0.1:4320/projects/coffee-journey/.

## Interaction

Switch between roast, grind, and brew. Adjust roast and milk, choose a cup color, and toggle steam.

## Files

`index.html` is the standalone entry point. `scene.js` owns this project’s model, controls, and animation. Shared rendering and interface code lives in `../../shared/`.

Model and font attribution is recorded in the root `CREDITS.md`.
