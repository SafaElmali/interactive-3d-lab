# CAN/DO

A draggable, scroll-driven lineup of seven soda cans, adapted from the original CAN/DO recreation.

## Run

From the repository root, run `npm run dev` and open http://127.0.0.1:4320/projects/can-do/.

## Interaction

Use arrow buttons, keyboard arrows, or horizontal dragging. Scroll vertically through the four compositions.

## Files

`index.html`, `main.js`, `motion.js`, and `style.css` implement the standalone experience. `scene.js` provides the gallery preview. Assets are stored in `assets/`.

Model and font attribution is recorded in the root `CREDITS.md`.
