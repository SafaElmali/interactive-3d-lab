# After Hours

The CC0 Khronos ToyCar model, with its display cloth removed.

## Run

From the repository root, run `npm run dev` and open http://127.0.0.1:4320/projects/car-garage/.

## Interaction

Choose paint colors, adjust lighting and clearcoat, or enable rotation. The shader masks green paint to preserve trim and wheels.

## Files

`index.html` is the standalone entry point. `scene.js` owns this project’s model, controls, and animation. Shared rendering and interface code lives in `../../shared/`.

Model and font attribution is recorded in the root `CREDITS.md`.
